# Make agent wiki guidance deterministic

## Why

The library's generic navigation prose had drifted from the canonical ambiguity and router-miss contract.

## What changed

Installed the canonical headless managed block with direct source lookup, one-page history lookup, exact weighted cross-page routing, sequential reads, exact-ID retries, and one fixed-string fallback. The curated component graph, GitHub evidence, human viewer, same-delivery authoring, Graphify protocol, and maintainer permission boundary remain repository-owned guidance.
